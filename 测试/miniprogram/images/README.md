# 图片资源说明

本项目需要以下图片资源，请将图片放入对应目录：

## TabBar 图标 (images/tab/)
- home.png - 首页图标（未选中）
- home-active.png - 首页图标（选中）
- service.png - 服务图标（未选中）
- service-active.png - 服务图标（选中）
- news.png - 资讯图标（未选中）
- news-active.png - 资讯图标（选中）
- mine.png - 我的图标（未选中）
- mine-active.png - 我的图标（选中）

## 功能图标 (images/icon/)
- consult.png - 智能咨询图标
- health.png - 健康管理图标
- service.png - 生活服务图标
- emergency.png - 紧急呼叫图标
- family.png - 家属联动图标
- news.png - 资讯中心图标
- robot.png - 机器人头像
- user.png - 用户默认头像

## 图片规格建议
- TabBar图标：81x81 像素
- 功能图标：100x100 像素
- 头像：200x200 像素

## 临时方案
如果暂时没有图片，可以使用以下占位符：
1. 在微信开发者工具中使用 base64 编码的占位图
2. 使用在线图标库如 iconfont.cn
3. 使用纯色背景作为临时图标
