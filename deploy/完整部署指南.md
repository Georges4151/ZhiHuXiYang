# 智慧养老平台完整部署指南

## 部署架构

```
┌─────────────────────────────────────────────────────────────┐
│                        云服务器                              │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  Nginx (80/443端口)                                   │  │
│  │  ├─ liyirou.top → 管理平台前端 (dist文件夹)            │  │
│  │  └─ api.liyirou.top → 后端服务 (8080端口)             │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  Java后端服务 (8080端口)                               │  │
│  │  └─ elderly-care-1.0.0.jar                           │  │
│  └──────────────────────────────────────────────────────┘  │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  MySQL数据库 (3306端口)                                │  │
│  │  └─ elderly_care 数据库                               │  │
│  └──────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────┘
                              │
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   ┌────▼────┐           ┌────▼────┐          ┌────▼────┐

   │ (内网穿透)│          │         │          │ .top    │
   └─────────┘           └─────────┘          └─────────┘
```

## 一、服务器环境准备

### 1.1 购买云服务器
- **推荐**: 阿里云、腾讯云、华为云
- **配置**: 2核4G 或以上（建议4核8G）
- **系统**: Ubuntu 22.04 LTS
- **带宽**: 5Mbps 或以上
- **存储**: 50GB SSD 或以上

### 1.2 配置安全组
开放以下端口：
| 端口 | 用途 | 说明 |
|------|------|------|
| 22 | SSH | 远程连接 |
| 80 | HTTP | 管理平台前端 |
| 443 | HTTPS | 管理平台前端（SSL） |
| 8080 | 后端API | Java服务 |
| 3306 | MySQL | 数据库（建议只开放内网） |

## 二、服务器环境安装

### 2.1 连接服务器
```bash
ssh root@你的服务器IP
```

### 2.2 更新系统
```bash
apt update && apt upgrade -y
```

### 2.3 安装JDK 17
```bash
apt install openjdk-17-jdk -y
java -version
```

### 2.4 安装MySQL 8.0
```bash
apt install mysql-server -y
systemctl start mysql
systemctl enable mysql

# 设置root密码
mysql -e "ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'YourStrongPassword123!';"
mysql -e "FLUSH PRIVILEGES;"

# 创建数据库
mysql -u root -pYourStrongPassword123! -e "CREATE DATABASE elderly_care CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
mysql -u root -pYourStrongPassword123! -e "CREATE USER 'elderly'@'localhost' IDENTIFIED BY 'ElderlyDbPass456!';"
mysql -u root -pYourStrongPassword123! -e "GRANT ALL PRIVILEGES ON elderly_care.* TO 'elderly'@'localhost';"
mysql -u root -pYourStrongPassword123! -e "FLUSH PRIVILEGES;"
```

### 2.5 安装Nginx
```bash
apt install nginx -y
systemctl start nginx
systemctl enable nginx
```

### 2.6 安装Node.js (用于构建前端)
```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs
node -v
npm -v
```

## 三、后端服务部署

### 3.1 创建应用目录
```bash
mkdir -p /opt/elderly/{backend,frontend,logs}
cd /opt/elderly
```

### 3.2 上传后端jar包
从本地上传到服务器：
```bash
# 在本地执行
scp "d:\养老\后端\target\elderly-care-1.0.0.jar" root@你的服务器IP:/opt/elderly/backend/
```

### 3.3 创建启动脚本
```bash
cat > /opt/elderly/backend/start.sh << 'EOF'
#!/bin/bash
APP_NAME=elderly-care-1.0.0.jar
LOG_FILE=/opt/elderly/logs/app.log

# 检查是否已在运行
PID=$(ps -ef | grep $APP_NAME | grep -v grep | awk '{print $2}')
if [ -n "$PID" ]; then
    echo "应用已在运行，PID: $PID"
    exit 1
fi

# 启动应用
nohup java -jar /opt/elderly/backend/$APP_NAME \
    --spring.profiles.active=prod \
    --server.port=8080 \
    >> $LOG_FILE 2>&1 &

echo "应用已启动，日志: $LOG_FILE"
sleep 2
tail -n 20 $LOG_FILE
EOF

chmod +x /opt/elderly/backend/start.sh
```

### 3.4 创建停止脚本
```bash
cat > /opt/elderly/backend/stop.sh << 'EOF'
#!/bin/bash
APP_NAME=elderly-care-1.0.0.jar

PID=$(ps -ef | grep $APP_NAME | grep -v grep | awk '{print $2}')
if [ -n "$PID" ]; then
    kill -15 $PID
    echo "应用已停止，PID: $PID"
else
    echo "应用未运行"
fi
EOF

chmod +x /opt/elderly/backend/stop.sh
```

### 3.5 创建生产环境配置文件
```bash
cat > /opt/elderly/backend/application-prod.yml << 'EOF'
server:
  port: 8080

spring:
  datasource:
    url: jdbc:mysql://localhost:3306/elderly_care?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai&useSSL=false
    username: elderly
    password: ElderlyDbPass456!
    driver-class-name: com.mysql.cj.jdbc.Driver
  
  servlet:
    multipart:
      max-file-size: 10MB
      max-request-size: 100MB

# 文件上传路径
file:
  upload:
    path: /opt/elderly/uploads

# JWT配置
jwt:
  secret: your-secret-key-change-this-in-production
  expiration: 86400000

# 日志配置
logging:
  level:
    root: INFO
    com.elderly: DEBUG
  file:
    name: /opt/elderly/logs/app.log
EOF
```

### 3.6 启动后端服务
```bash
cd /opt/elderly/backend
./start.sh
```

## 四、管理平台前端部署

### 4.1 本地构建前端
在本地Windows上执行：
```powershell
cd "d:\养老\管理平台前端"
npm install
npm run build
```

构建完成后，`dist` 文件夹将包含所有静态文件。

### 4.2 上传前端文件到服务器
```bash
# 在本地执行，上传整个dist文件夹
scp -r "d:\养老\管理平台前端\dist" root@你的服务器IP:/opt/elderly/frontend/
```

### 4.3 配置Nginx
```bash
cat > /etc/nginx/sites-available/elderly-admin << 'EOF'
server {
    listen 80;
    server_name liyirou.top www.liyirou.top;
    
    # 前端静态文件
    location / {
        root /opt/elderly/frontend/dist;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    # 后端API代理
    location /api/ {
        proxy_pass http://127.0.0.1:8080/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 管理后台API代理
    location /admin/ {
        proxy_pass http://127.0.0.1:8080/admin/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
    
    # 上传文件访问
    location /uploads/ {
        alias /opt/elderly/uploads/;
    }
}
EOF

# 启用站点
ln -sf /etc/nginx/sites-available/elderly-admin /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default

# 测试配置
nginx -t

# 重启Nginx
systemctl restart nginx
```

## 十、故障排查

### 10.1 无法访问管理平台
1. 检查Nginx是否运行：`systemctl status nginx`
2. 检查防火墙：`ufw status`
3. 检查安全组配置
4. 查看Nginx错误日志：`tail -f /var/log/nginx/error.log`

### 10.2 后端API无法访问
1. 检查Java进程：`ps -ef | grep elderly`
2. 查看应用日志：`tail -f /opt/elderly/logs/app.log`
3. 检查端口监听：`netstat -tlnp | grep 8080`
4. 测试本地访问：`curl http://localhost:8080/api/health`

### 10.3 数据库连接失败
1. 检查MySQL状态：`systemctl status mysql`
2. 检查用户名密码是否正确
3. 检查数据库是否存在：`mysql -u elderly -p -e "SHOW DATABASES;"`
4. 检查连接权限：`mysql -u elderly -p -e "SELECT user,host FROM mysql.user;"`

### 10.4 小程序请求失败
1. 检查服务器域名是否已配置
2. 检查HTTPS证书是否有效
3. 检查后端是否正常运行
4. 查看小程序开发者工具网络请求详情
